# Claude Code に貼る指示文

以下をそのまま Claude Code（YouTube にアクセスできる環境）に渡してください。

---

このリポジトリ `kaiken-scan` は、政党公式YouTubeの記者会見から特定テーマの発言を
タイムスタンプ付きで抜き出すためのものです。次をやってください。

## 背景

2026年8月28日、中道改革連合・立憲民主党・公明党の3党党首会談で、
立憲民主党が合流しない方針を伝え、3党合流は見送りになりました。
経緯と現時点で分かっていることは `HANDOFF.md` にまとめてあります。

## やってほしいこと

### 1. 榛葉幹事長（国民民主党）の言及を全部出す

```bash
pip install -r scripts/requirements.txt
python3 scripts/scan.py --config config/shimba_kokumin.json --outdir output/shimba
```

国民民主党公式チャンネル（https://www.youtube.com/channel/UCJc_jL0yOBGychLgiTCGtPw ）の
榛葉幹事長 定例会見（毎週金曜14時）を2026年1月〜現在まで全部走査し、
`中道／中道改革連合／合流／立憲／公明／3党／統一会派／政界再編` に触れた箇所を、

- 会見の日付とタイトル
- **`h:mm:ss` のタイムスタンプ**
- **`&t=` 付きの会見リンク**
- 前後2〜3分の逐語

の形で `output/shimba/report.md` に出してください。

### 2. 小川淳也代表（中道改革連合）の言及を出す

```bash
python3 scripts/scan.py --config config/ogawa_chudo.json --outdir output/ogawa
```

中道改革連合公式チャンネル（https://www.youtube.com/@CRAJ2026 ）が対象です。

### 3. 特に確認してほしい日

| 日付 | 何を見るか |
|---|---|
| **2026-08-28（金）** | 見送り伝達の当日。榛葉会見は14時、党首会談は16:45なので**会見は会談前**。前日8/27の報道への反応が入っているはず |
| **2026-09-04（金）** | 会談後の最初の金曜会見。ここが本命の可能性が高い |

| 2026-07-31 | 3党党首会談・中間整理 |

### 4. 出力後にやること

- `report.md` のヒットは**自動生成字幕**由来です。`&t=` リンクを開いて音声で確認し、
  誤変換を直したうえで `HANDOFF.md` の各記録を
  **タイムスタンプ入りの確定版に更新**してください。
- 現状 `HANDOFF.md` は報道からの推定で、タイムスタンプは全件「未取得」です。
- 特に `HANDOFF.md` の **S-4「1＋1は2にもならなかった、計算したら0.28」**は
  定例会見での発言か島根での党会合での発言かが未確定です。ここを決着させてください。
  （BSS山陰放送の記事: https://www.excite.co.jp/news/article/bss_1442108555259118348/ ）

### 5. 注意

- `HANDOFF.md` の記述は検索スニペットからの再構成で、一次ソースにあたれていません。
  矛盾を見つけたら報道記事を確認して直してください。
- 引用として公開する場合は、日付・会見名・発言者を必ず併記してください。
